# September 13, 2026: a guide to Persistent AI, with refreshed sources

This refresh introduces Persistent AI to people exploring AI companions with
memory, personalization and continuity over time. The original Her image and
that imaginative starting point frame an independent catalog, with Nova Seed
and Nova Tools included as disclosed options among many.

## What changed

- Restored the original Her image and added a human-facing introduction and
  navigation for understanding the field, creating a companion and exploring memory.
- Replaced the narrow Nova Tools entry with the current coordination suite, and
  used the Nova Seed and Nova Tools public names. Fixed three moved Nova document
  links: ADOPTING, MECHANISMS and REFERENCES now live under docs/.
- Refreshed all 23 existing framework, seed and tooling descriptions against
  primary documentation. Corrected Letta's current source location, qualified
  SoulClaw's claims, clarified Graphiti's relationship to Zep, and marked Agent
  File as historical with its exclusions and current Letta Code deprecation.
- Added three memory options with distinct approaches: Basic Memory's shared
  Markdown notes, Honcho's peer/session context, and Hindsight's memory banks.
- Refreshed individual, writing, lineage and governance summaries; removed
  unnecessary popularity counts, current-availability assumptions and rankings.
  Updated two paper titles and described the Always-On Agents survey as its
  authors do: a scoped corpus, not an exhaustive census.
- Kept the project-specific governance differences, public writing, historical
  formats, contributor invitation, supporter link and license visible.

## Evidence and limits

This is a primary-source documentation and link review, not an installation test,
security certification, benchmark reproduction or proof of sentience. Project
capabilities are descriptions of their public artifacts. A working URL does not
establish that a service is online or that every claim in its documentation holds.

The [infrastructure review](RESEARCH-INFRASTRUCTURE-2026-09-13.md) covers 23 existing
entries and three researched additions, with 27 pinned README snapshots and
specific source caveats. Its proposed wording informed the integrated catalog.
